# Community Comparison

仅在用户明确要求社区技巧，或本周本地摩擦明显需要外部对照时加载。

```
Local evidence → Community practice → Compare → Candidate
```

社区实践只能：解释本地问题 / 提供已有解决方案 / 帮助判断设计方向。**不能仅因为「社区流行」就 promote。**

优先参考：

- Agent Skills 官方规范
- Anthropic / Claude Code 官方实践
- 有明确实验或验证证据的经验

丢弃：

- 没有证据的热点技巧
- 单人偶然经验
- 与本周摩擦无关的技巧
- 需要复杂基础设施才能获得微小收益的方案

检索结果只作为 *Community Inspiration*，不直接成为 *Local Rule*。硬规则仍适用：**Community practice can explain a local problem, but cannot create a local problem.**
