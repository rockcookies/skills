## Agents & rules

`npx skills add` installs **skills only**. Agents (`agents/`) and rules (`rules/`) are plain markdown files that must be copied into your tool's directories by hand. The [catalog site](https://rockcookies.github.io/skills/) generates ready-to-run download commands for bash / PowerShell / cmd.
